# BonusHub

BonusHub is a private, CEO-only relationship command centre. The active product is a responsive web application in [`web/`](web/README.md). It uses Next.js, React, strict TypeScript, Tailwind CSS, TanStack Query, React Hook Form, Zod, Recharts, Radix primitives, and Lucide icons.

```bash
cd web
npm install
npm run dev
```

The retired native Apple prototype is preserved under `legacy/apple-prototype/` for domain-reference history only. It is not part of the active build, test, or deployment path.
